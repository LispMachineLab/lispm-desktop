#+title: Change settings
#+description: Read and change LispM's settings, as Control Panels holds them: the look and the colour theme, the desktop's colour and picture, the language, the keys, the proxy and the browser, the agents' model, permissions, memory and sandbox, LispM's password, whether LispM starts as the desktop or in Focus Mode (its terminal) at its next start, what opens at login and at startup, the Emacs LispM runs on, and how software updates; open a panel for the user, or list it in Focus Mode.

Control Panels holds LispM Desktop's settings: a control panel for each category, an application
of its own whose window's tabs are its panels, which the user opens from the menu bar's λ menu or
the desktop's Control Panels folder.  Appearance holds the Appearance and Desktop panels;
General, Language, Keyboard and Startup; Internet, Internet and Network; Agents, LispM and
Sandbox; Security, Security; System, Kernel and Software Update.  Each choice takes effect at
once where it can, and is saved for later starts.  This skill gives you tools to
read the settings, change them, and show the user a panel; and names the functions behind them
for ~eval_elisp~.

* Reading

- ~settings_get~: every setting, by name, with its value, the values it takes, and the panel it
  is on; with SETTING, that one alone.
- ~settings_show~ PANEL: open the control panel holding a panel, on that panel, for the user to
  look or choose themselves: ~themes~ (Appearance), ~desktop~, ~keyboard~, ~language~, ~browser~
  (Internet), ~network~, ~lispm~, ~sandbox~, ~security~, ~startup~, ~kernel~ or ~update~
  (Software Update), or ~apps~ (the App Store's applications, see the app-store skill).
  It changes nothing.  When LispM runs as its terminal (Focus Mode) there are no Control Panels:
  ~settings_show~ lists the panel's settings in the minibuffer instead, and TAB in
  ~*Completions*~ lists them all; C-g closes the list.  The same list is the tool's result.

* Changing

- ~settings_set~ SETTING VALUE: change a setting, now and for later starts.  It is of the
  permission class ~write~, and asks the user before every change, whatever their policy says:
  say in one short line what you are about to change and to what, then call it.  The settings:

  - ~look~: the forms the windows, menus and title bars are drawn in, ~platinum~ (classic), ~win3~ or ~genera~.
  - ~theme~: the appearance and colour theme, ~dracula~, ~platinum~, ~win3~ or ~genera~.
  - ~language~: the language LispM's menus and windows speak, ~computer~ for the computer's own,
    or ~en-US~, ~en-GB~, ~de~, ~fr~, ~ja~, ~zh-Hans~, ~zh-Hant~.  What agents say is not changed.
  - ~editing-style~: ~vim~ or ~emacs~ keys in files; it takes effect at the next start.
  - ~proxy-type~: ~none~, ~http~ or ~socks5~, the proxy every connection LispM makes goes through;
    ~proxy-server~, its address, HOST:PORT; ~proxy-exceptions~, the hosts reached directly,
    separated by commas.
  - ~desktop-color~: ~theme~ to follow the theme, or a colour, ~#RRGGBB~ or a name Emacs knows;
    ~desktop-picture~, a picture file, or ~none~; ~desktop-picture-position~, ~fill~, ~fit~,
    ~center~ or ~tile~.
  - ~browser-home~: the page Home opens; ~browser-search~: the address searched for what is typed
    as an address, ~%s~ standing for the words.
  - ~sandbox~: how strictly agents' shell commands and MCP servers are confined: ~none~, ~low~,
    ~middle~, ~high~, or ~custom~, the user's own rules.  ~settings_set~ only makes it stricter;
    see below.
  - ~sandbox-domains~: the domains sandboxed commands may reach at Low and Middle, separated by
    commas.  At ~custom~, the rules: ~sandbox-rule-allow-read~, ~sandbox-rule-deny-read~,
    ~sandbox-rule-allow-write~, ~sandbox-rule-deny-write~ and ~sandbox-rule-unix-sockets~ take
    file names separated by commas; ~sandbox-rule-allowed-domains~ and
    ~sandbox-rule-denied-domains~ take domains; ~sandbox-rule-local-binding~,
    ~sandbox-rule-pty~ and ~sandbox-rule-apple-events~ take ~true~ or ~false~.
  - ~start-as~: what LispM starts as at its next start, ~desktop~ (windows, menus and
    applications) or ~terminal~ (Focus Mode, LispM's terminal: the sessions, a listener and a
    who line, without the desktop); nothing changes now.  Change it only when the user asks what LispM is
    to start as, as "always start in Focus Mode" or "in console mode".  To go into the terminal now
    (Focus Mode, console, TUI, terminal or keyboard mode) or back to the desktop (desktop mode), use ~terminal_enter~ or
    ~terminal_leave~ of the skill terminal instead: they switch at once, and back to the
    desktop where LispM started as the terminal.
  - ~open-at-login~: ~true~ to have the computer open LispM when the user logs in.
  - ~startup-item~, with ITEM: what LispM opens once started.  VALUE ~on~ or ~off~ turns the
    item named ITEM on or off, ~remove~ takes it out; ~add~ adds ITEM, an application's key or a
    file or folder, at the end.  Programs, services and Emacs commands are added with
    ~startup-program~, ~startup-service~ and ~startup-command~.
  - ~startup-program~, with ITEM a name: VALUE, a shell command, run in the background at every
    start; DIRECTORY, where it runs, the home directory without it.  ~startup-command~, with ITEM
    a name: VALUE, an Emacs command called at every start.  ~startup-service~, with ITEM a
    sandbox level: VALUE, a service's id, run in the sandbox at that level.  ~service-level~,
    with ITEM a service: VALUE ~low~, ~middle~ or ~high~, the level it runs at from now on.
  - ~model~: ~BACKEND/MODEL~, as ~openai/gpt-5.5~, or a model that one backend serves;
    ~effort~: ~low~, ~medium~, ~high~, ~xhigh~ or ~max~; ~permission~, with ITEM a class of tools,
    ~read~, ~memory~, ~comm~, ~lisp~, ~write~, ~shell~, ~exec~, ~mcp~ or ~web~, and VALUE
    ~auto~ (no asking), ~ask~ or ~deny~.
  - ~compact-size~: when conversations are summed up, ~small~, ~medium~, ~large~ or ~asked~;
    ~compact-idle~, ~compact-save-memory~, ~git~ and ~episodes~: ~true~ or ~false~;
    ~memory-size~: ~small~, ~medium~, ~large~ or ~unlimited~; ~memory-model~: a model, or ~own~
    for each agent's; ~default-role~: a role's name; ~skill-directory~, with ITEM a directory:
    VALUE ~add~ or ~remove~.
  - ~password~: read only, how LispM's password stands; ~desktop-requires-password~: ~true~ when
    the Desktop's start asks for it.  The password itself is never a setting, and never yours:
    see Security below.
  - ~update-check-automatically~ (~true~ or ~false~), ~update-schedule~ (~daily~ or ~weekly~),
    ~update-install-automatically~ (~true~ installs LispM's updates by themselves, as it quits;
    ~false~ asks first) and ~store-update-automatically~ (whether the App Store's applications
    update by themselves).
  - ~kernel~: ~true~ to have LispM Kernel run LispM's background work; ~emacs-build~, the major
    version of the Emacs LispM.app switches to, where LispM runs in LispM.app.

* The sandbox

The sandbox confines you and the other agents.  Make it stricter with ~settings_set~ when the
user asks.  To lower it, or to choose or leave ~custom~, use ~settings_lower_sandbox~ LEVEL,
which asks the user every time, whatever their policy says; do so only when the user asked for
that level, and never to get around something the sandbox stopped: tell the user what was
stopped instead.  The Custom level's rules change with ~settings_set~ only while the level is
~custom~; the domains sandboxed commands may reach at Low and Middle change with
~settings_set~ ~sandbox-domains~ at any level.

* Security

LispM's keys are kept encrypted, and only the user's password opens them.  The password is
never passed to you and you must never ask for it, repeat it, or write it anywhere.  The user
types it themselves, in the native minibuffer in Focus Mode, or on the password page on the desktop:

- ~security_change_password~ asks for the old password if a store exists, then the new password
  twice; the user types each themselves.  It takes no parameters.
- ~security_lock~ forgets the keys until the password is given again.  It takes no parameters.
- ~settings_set~ ~desktop-requires-password~ says whether the Desktop's start asks for the
  password next time.  LispM, its agents and the editor always ask; a game that uses no key
  never does.

Both security tools ask the user before they run, as every change does.  Say in one line what
you are about to do, then call the tool; the user types the password without it ever reaching you.

* Care

Change a setting only when the user asked for it, and tell them what you changed.  When they ask
for something no setting here holds, show them the panel nearest to it rather than guessing.
Changing a setting with ~settings_set~ asks them first; a refusal leaves it as it was.

* Beyond the tools

With ~eval_elisp~: ~(lispm-desktop-set-theme 'THEME)~, ~(lispm-desktop-set-look 'LOOK)~ and
~(lispm-desktop-set-language 'TAG)~ change what their settings do; ~lispm-desktop-settings-panels~
lists the panels; ~(lispm-desktop-settings-show 'PANEL)~ opens one; ~lispm-desktop-startup-items~
holds the startup items, documented there.

Some buttons do a thing once rather than leave a value; they have no setting, and ~eval_elisp~
holds the function, approved as any call is: ~lispm-desktop-arrange-icons~,
~lispm-browser-clear-history~, ~lispm-desktop-browser-edit-bookmarks~,
~lispm-desktop-settings--add-backend~ and its Change and Remove, ~lispm-untrust-skill~,
~lispm-open-memory~, ~lispm-desktop-settings--sandbox-start-from~, ~lispm-sandbox-install~,
~lispm-desktop-kernel-restart~, ~lispm-desktop-emacs-cancel~ and ~lispm-desktop-emacs-restart~,
~lispm-desktop-update-now~, ~lispm-desktop-update-restart~, ~lispm-desktop-update-show-log~ and
~lispm-desktop-startup-open-item~.

(defun lispm-desktop-skill-boolean (value)
  "VALUE, a string, as t or nil; an error if it says neither."
  (pcase (downcase (string-trim value))
    ((or "true" "t" "on" "yes" "1") t)
    ((or "false" "nil" "off" "no" "0") nil)
    (_ (error "%s is neither true nor false: write true or false" value))))

(defun lispm-desktop-skill-choice (value choices)
  "The entry of CHOICES, symbols or strings, that VALUE, a string, names.
Signal an error when it names none."
  (let ((name (downcase (string-trim value))))
    (or (seq-find (lambda (choice)
                    (equal name (downcase (format "%s" choice))))
                  choices)
        (error "%s is not one of %s" value
               (mapconcat (lambda (choice) (format "%s" choice)) choices ", ")))))

(defun lispm-desktop-skill-save (variable value)
  "Set VARIABLE to VALUE now and for later starts, as Control Panels does."
  (customize-save-variable variable value))

(defun lispm-desktop-skill-list-text (entries)

(defun lispm-desktop-skill-sandbox-levels ()

(defun lispm-desktop-skill-stricter-p (level)
  "Non-nil when sandbox LEVEL confines more than the level now."
  (let ((from (seq-position lispm-desktop-skill-strictness lispm-sandbox-level))
        (to (seq-position lispm-desktop-skill-strictness level)))
    (and from to (> to from))))

(defun lispm-desktop-skill-domain-list (value &optional deny)
  "VALUE, domains separated by commas or spaces, as a list srt takes.
With DENY, * is allowed.  Signal an error for a domain srt cannot take."
  (let ((domains (split-string (string-trim value) "[, \t\n]+" t)))
    (let ((wrong (seq-remove (lambda (domain)
                               (or (lispm-desktop-settings--sandbox-domain-p domain)
                                   (and deny (equal domain "*"))))
                             domains)))
      (when wrong
        (error "srt cannot %s %s: write a domain as example.com, *.example.com or example.com:443"
               (if deny "deny" "allow") (string-join wrong ", "))))
    domains))

(defun lispm-desktop-skill-custom-rule ()
  "Signal an error unless the sandbox is at the Custom level."
  (unless (eq lispm-sandbox-level 'custom)
    (error "The Custom rules change at Custom only: choose custom with settings_lower_sandbox first")))

(defun lispm-desktop-skill-model-text ()
  "The model agents that name none use, BACKEND/MODEL."
  (let* ((status (lispm-model-status))
         (backend (plist-get status :backend))
         (model (plist-get status :model)))
    (if model (format "%s/%s" backend model) "none")))

(defun lispm-desktop-skill-model-choice (value)
  "The (BACKEND . MODEL) VALUE names; an error when it names none or several."
  (let ((text (string-trim value)))
    (if (string-match "\\`\\([^/]+\\)/\\(.+\\)\\'" text)
        (let ((backend (intern (match-string 1 text)))
              (model (string-trim (match-string 2 text))))
          (unless (or (assq backend lispm-backends)
                      (eq backend (plist-get (lispm-model-status) :backend)))
            (error "No backend %s: settings_get model lists the models" backend))
          (cons backend model))
      (let ((found (delete-dups
                    (mapcar (lambda (choice)
                              (cons (plist-get choice :backend)
                                    (plist-get choice :model)))
                            (seq-filter (lambda (choice)
                                          (equal (plist-get choice :model) text))
                                        (lispm-model-choices))))))
        (pcase found
          (`((,backend . ,model)) (cons backend model))
          ('nil (error "%s is no model settings_get lists: write BACKEND/MODEL" value))
          (_ (error "%s is a model of more than one backend: write BACKEND/%s"
                    value text)))))))

(defun lispm-desktop-skill-permission-text ()
  "What the default policy lets each class of tools do."
  (mapconcat (lambda (entry)
               (format "%s %s" (car entry) (lispm-default-permission (car entry))))
             lispm-permission-classes "; "))

(defun lispm-desktop-skill-directory-text ()
  "The directories agents read skills from."
  (if lispm-skill-directories
      (mapconcat (lambda (directory) (abbreviate-file-name directory))
                 lispm-skill-directories ", ")
    "none"))

(defun lispm-desktop-skill-change-skill-directory (value item _directory)
  "Add or remove ITEM, a directory of skills, as VALUE says."
  (unless item (error "Name the directory, ITEM"))
  (let ((action (downcase (string-trim value)))
        (directory (file-name-as-directory (expand-file-name (string-trim item)))))
    (pcase action
      ("add"
       (unless (file-directory-p directory)
         (error "%s is no directory" directory))
       (lispm-add-skill-directory directory t))
      ("remove"
       (when (lispm-skill-directory-builtin-p directory)
         (error "LispM's own skills stay where they are"))
       (unless (seq-find (lambda (other)
                           (equal (file-truename (file-name-as-directory other))
                                  (file-truename directory)))
                         lispm-skill-directories)
         (error "%s is no directory of skills" directory))
       (lispm-remove-skill-directory directory t))
      (_ (error "VALUE is add or remove, not %s" value)))))

(defun lispm-desktop-skill-startup-index (name)
  "The index of the startup item NAME, case ignored; an error if none."
  (or (seq-position (mapcar (lambda (item) (downcase (lispm-desktop-startup-item-name item)))
                            lispm-desktop-startup-items)
                    (downcase (string-trim name)))
      (error "No startup item %s: settings_get startup-item lists them" name)))

(defun lispm-desktop-skill-startup-item (what)
  "The startup item opening WHAT: an application's key, else a file or folder."
  (let ((app (intern (string-trim what))))
    (if (assq app lispm-desktop-apps)
        (list :app app)
      (let ((file (expand-file-name what (if (and (boundp 'lispm-current-agent) lispm-current-agent)
                                             (lispm-agent-root lispm-current-agent)
                                           default-directory))))
        (unless (file-exists-p file)
          (error "%s is no application's key, nor a file or folder" what))
        (list :file (abbreviate-file-name file))))))

(defun lispm-desktop-skill-startup-change (item value)
  "Turn the startup item ITEM on or off, remove it, or add it, as VALUE says."
  (let ((action (downcase (string-trim value))))
    (cond
     ((equal action "add")
      (lispm-desktop-settings--startup-add-item
       (lispm-desktop-skill-startup-item item)))
     ((member action '("on" "off" "remove"))
      (let ((index (lispm-desktop-skill-startup-index item)))
        (lispm-desktop-skill-save
         'lispm-desktop-startup-items
         (if (equal action "remove")
             (append (seq-take lispm-desktop-startup-items index)
                     (seq-drop lispm-desktop-startup-items (1+ index)))
           (seq-map-indexed (lambda (old i)
                              (if (= i index)
                                  (lispm-desktop-startup-item-with old :disabled (equal action "off"))
                                old))
                            lispm-desktop-startup-items)))))
     (t (error "A startup item's VALUE is on, off, remove or add")))))

(defun lispm-desktop-skill-startup-text (&optional kind)
  "The startup items, a line each; with KIND, those of that kind."
  (let ((items (if kind
                   (seq-filter (lambda (item)
                                 (eq (lispm-desktop-startup-item-kind item) kind))
                               lispm-desktop-startup-items)
                 lispm-desktop-startup-items)))
    (if (null items)
        "none"
      (mapconcat (lambda (item)
                   (format "%s (%s %s%s)" (lispm-desktop-startup-item-name item)
                           (lispm-desktop-startup-item-kind item)
                           (plist-get item (intern (format ":%s" (lispm-desktop-startup-item-kind item))))
                           (if (plist-get item :disabled) ", off" "")))
                 items "; "))))

(defun lispm-desktop-skill-add-program (value item directory)
  "Add VALUE, a shell command, run at startup, called ITEM, in DIRECTORY."
  (let ((command (string-trim value)))
    (when (string-empty-p command)
      (error "Write the program as a shell command, VALUE"))
    (let* ((directory (and directory (not (string-empty-p (string-trim directory)))
                           (string-trim directory)))
           (directory (and directory
                           (abbreviate-file-name
                            (file-name-as-directory (expand-file-name directory)))))
           (default (lispm-desktop-startup-program-name command))
           (name (and item (string-trim item))))
      (when (and directory (not (file-directory-p directory)))
        (error "%s is no directory" directory))
      (lispm-desktop-settings--startup-add-item
       `(:program ,command
         ,@(when (and directory (not (equal directory "~/")))
             (list :directory directory))
         ,@(when (and name (not (string-empty-p name)) (not (equal name default)))
             (list :name name)))))))

(defun lispm-desktop-skill-choose-panel ()

          (quit nil))))
