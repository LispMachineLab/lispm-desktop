#+title: LispM Desktop

#+HTML: <p align="center"><a href="https://github.com/LispMachineLab/lispm-desktop/actions/workflows/test.yml"><img src="https://github.com/LispMachineLab/lispm-desktop/actions/workflows/test.yml/badge.svg" alt="test" /></a></p>

LispM's Emacs distribution: Emacs laid out as Mac OS 9's desktop and set up as a workspace for
coding agents, ready from the first start.  [[https://github.com/LispMachineLab/lispm-agent][LispM Agent]]'s agents, Claude Code and Codex
share its sidebar, [[https://github.com/LispMachineLab/lispm-browser][LispM Browser]] is its web browser, and its App Store installs more.  In
code, the prefix is ~lispm-desktop-~.

* The LispM projects

| [[https://github.com/LispMachineLab/lispm-agent][lispm-agent]]     | AI agents inside Emacs                                            |
| *lispm-desktop* | Emacs as a Mac OS 9 desktop, set up as a workspace for agents (this repository) |
| [[https://github.com/LispMachineLab/lispm-browser][lispm-browser]]   | a WebKit browser in Emacs, with keyboard hints and Chrome extensions |
| [[https://github.com/LispMachineLab/lispm-store][lispm-store]]     | the catalog LispM Desktop's App Store installs from               |

The agents and the browser each stand on their own; LispM Desktop installs both at its first start.

* Installation

** LispM.app, on macOS

On macOS 11 or later, Apple silicon or Intel:

#+begin_src sh
curl -fsSL https://lispm.ai/install.sh | sh
#+end_src

[[file:install.sh][install.sh]] checks out this repository, lispm-agent and lispm-browser in =~/.lispm=,
and makes =/Applications/LispM.app= from a signed, notarized GNU Emacs of
[[https://github.com/jimeh/emacs-builds][jimeh/emacs-builds]], whose checksum and signature it checks.
Nothing needs to be known about Emacs to use it.  LispM keeps itself up to date (see
[[*Updating][Updating]]); to uninstall, delete =/Applications/LispM.app= and =~/.lispm=.

** In your own Emacs

Emacs 30.1 or later (31 recommended) built with SVG images, git and curl, on macOS or GNU/Linux:

#+begin_src sh
git clone https://github.com/LispMachineLab/lispm-desktop ~/lispm-desktop
emacs --init-directory ~/lispm-desktop     # or make it your config: ln -s ~/lispm-desktop ~/.emacs.d
#+end_src

The first start asks for Vim or Emacs keys and an appearance, installs the packages (a few
minutes, once), then tours the desktop.  LispM Agent and LispM Browser are taken from
~load-path~, else from checkouts beside this one (=../lispm-agent=, =../lispm-browser=), else
installed with package-vc.  Give the agents a model with ~OPENAI_API_KEY~ or ~ANTHROPIC_API_KEY~,
or see LispM Agent's [[https://github.com/LispMachineLab/lispm-agent#backends][Backends]].

Optional, used when present:

- ~claude~ and ~codex~ on ~PATH~ (Hermes once the App Store has added it);
- Rust's ~cargo~, to build the terminal module; without it a prebuilt, checksummed one is downloaded;
- Swift, on macOS 15.4+, for the browser's Chrome extensions;
- an Emacs built with xwidgets, for the browser;
- the Maple Mono NF CN font, which keeps terminal columns aligned with CJK;
- aspell, hunspell or ispell, for Flyspell.

* What you get

- *Looks and themes*: Mac OS 9's Platinum, Windows 3.2 or OS/2 2.0's Workplace Shell, in the
  Dracula, Platinum, Windows 3.2 or OS/2 colour theme, or any theme installed.
- *A desktop* with Mac OS 9's icons down its right edge (home disk, Emacs, browser,
  Applications, App Store, Control Panels, Trash), dragged with the mouse or selected with
  =C-n= =C-p= =C-f= =C-b=, over a colour or a picture of your own.
- *A guide* that tours the desktop at the first start, Apple Guide style, with coach marks and
  Show Me (=C-c ?= brings it back).
- *Finder windows*: folders as large icons, with back, forward, up, rename and Move to Trash;
  an item dragged onto the desktop's Trash is thrown away.
- *Applications*, one in front at a time: the desktop, the editor, the browser and whatever the
  App Store installed, each filling the menu bar with its menus beside the rainbow λ.  One
  installed is uninstalled from its right-click menu, in the App Store or the Applications
  folder, or by dragging it onto the Trash; what it alone brought, Homebrew programs and Emacs
  packages, goes too when asked.
- *The editor*, full screen or floating: a sidebar of Files, Agents and Shells, a workspace per
  project (=C-<tab>=, =M-`= for thumbnails), chats and terminals on the left, files on the right.
- *Platinum windows*: title bars with close, zoom and collapse boxes, scroll bars, placards,
  grow boxes, outline moves and resizes, Mac OS 9 menus and alerts, Balloon Help.
- *Agents side by side*: sessions of LispM, Claude Code, Codex and App Store agents (Hermes),
  listed per project.  Claude Code and Codex see the selection, open files and diagnostics;
  programs speaking the [[https://superlogical.com/rex/docs/build/program-status][Program Status Protocol]] show working, done or waiting in their title
  bars (=C-c a n= goes to the next one waiting).
- *Terminals that never stall Emacs*: each emulated on a thread of its own by a Rust module
  built on [[https://github.com/alacritty/alacritty][Alacritty]]'s terminal (=native/lispm-desktop-term=); Emacs redraws only those on
  screen.  Eat stands in until the module is built or downloaded.
- *Control Panels*: Appearance, Desktop, Keyboard, Internet, Network, Sandbox, Startup and
  Software Update, plus a Control Strip along the desktop's edge (=C-c b=, =C-c B=).
- *The App Store*: applications (Elfeed, EMMS, ERC, Slack, Telega, Calc, games, ...) and
  extensions from [[https://github.com/LispMachineLab/lispm-store][lispm-store]], pinned to reviewed commits, installed in the background with the
  Homebrew programs they need.  Their windows get title bars, buttons, placards, menus and
  alerts worked out from their keymaps (~lispm-desktop-app-ui-define~ describes the rest).
- *A browser*, in Emacs built with xwidgets: LispM Browser drawn as Netscape Communicator, with
  tabs, history, bookmarks, Vimium-style hints and, on macOS 15.4+, Chrome extensions.
- *Windows out on the screen*, on macOS: a floating window dropped past the desktop's edge joins
  the Mac's own windows, as in Parallels' Coherence; =C-c h= hides the desktop in the Dock.
- *A watch on the pointer* while Emacs is busy, as Mac OS 9 showed it.
- *A modern Emacs underneath*: Vertico, Orderless, Consult, Embark, Corfu, Magit, Eglot,
  tree-sitter; Evil with =SPC= as leader if you chose Vim keys.
- *EXWM*: on an X display with no window manager, Emacs becomes it.

Title bars and menus use Charcoal, else Chicago (or ChicagoFLF), else Geneva.

* Keys

| Key                        | Does                                                         |
|----------------------------+--------------------------------------------------------------|
| =C-c ?=                    | the guide (=C-u=: from the start)                            |
| =C-c o=                    | the next application                                         |
| =C-c m=                    | the menu bar from the keyboard                               |
| =C-c c=                    | the right-click menu of what point is on                     |
| =C-c s=                    | into the sidebar and back                                    |
| =C-c u=                    | the window's title menu: a Finder's path, else its buffers   |
| =C-c h=                    | hide the desktop in the Dock, or show it again (macOS)       |
| =C-c b=, =C-c B=           | the Control Strip from the keyboard; hide or show it         |
| =C-c a l=                  | a LispM agent in this project (=C-u=: pick a role)           |
| =C-c a c=, =x=, =h=        | Claude Code, Codex or Hermes in this project                 |
| =C-c a s=, =C-c a a=       | resume a session; show or hide the agents view               |
| =C-c a r=                  | send a reference to the region to a running agent            |
| =C-c a n=                  | the next terminal waiting for you                            |
| =C-c t=, =C-c d=           | a new terminal; Dirvish                                      |
| =C-<tab>=, =C-S-<tab>=     | the next, the previous workspace                             |
| =M-`=, =C-c w=             | the workspaces as thumbnails                                 |
| =M-[=, =M-]=, =M-r=, =M-.= | browser: back, forward, reload, stop                         |
| =M-l=, =M-d=, =M-b=, =M-y= | browser: address, bookmark, bookmarks, history               |
| =M-t=, =M-}=, =M-{=, =M-w= | browser: new tab, next, previous, close                      |
| =f=, =F=, =i=, =M-e=       | page: follow a hint, in a new tab; first field; an extension |

In the Mac build Command is Meta, so Command-C and Command-V copy and paste everywhere.  With
Vim keys, =SPC= opens the leader and which-key shows what follows.

* Your own settings

Control Panels keep their choices for the next start.  =personal.el=, next to =init.el= and
ignored by git, is loaded after setup and can change anything:

#+begin_src emacs-lisp
(setq lispm-desktop-look 'platinum              ; platinum, win3 or os2
      lispm-desktop-theme 'platinum             ; dracula, platinum, win3, os2 or any theme
      lispm-desktop-color "#6666AA"             ; the desktop's colour
      lispm-desktop-picture "~/Pictures/desktop.jpg"
      lispm-desktop-picture-position 'fill)     ; fill, fit, center or tile
#+end_src

To use LispM Desktop as a library in a configuration of your own:

#+begin_src emacs-lisp
(add-to-list 'load-path "~/lispm-desktop/lisp")
(setq lispm-desktop-editing-style 'vim)         ; or 'emacs; nil asks
(require 'lispm-desktop)
(lispm-desktop-setup)
#+end_src

** A proxy

The Network panel sends every connection through one HTTP or SOCKS5 proxy: url.el's, the
programs Emacs starts (through =http_proxy= and friends) and the browser's pages.  Local
addresses and ~lispm-desktop-proxy-exceptions~ connect directly.

#+begin_src emacs-lisp
(setq lispm-desktop-proxy-type 'socks5          ; or 'http; nil for none
      lispm-desktop-proxy-server "127.0.0.1:7890")
#+end_src

** The sandbox

The Sandbox panel sets how strictly LispM Agent confines the commands and MCP servers its agents
run: None (the default), Low, Middle, High, or Custom rules edited in the panel.  See LispM
Agent's [[https://github.com/LispMachineLab/lispm-agent#the-sandbox][sandbox]].

#+begin_src emacs-lisp
(setq lispm-sandbox-level 'middle
      lispm-sandbox-allowed-domains '("api.example.com" "*.example.org"))
#+end_src

** Startup

The Startup panel opens LispM at login (a launch agent on macOS, an XDG autostart entry on
GNU/Linux) and opens startup items once the desktop shows: applications, documents, folders,
Emacs commands, and programs run in the background while LispM runs, their output in
=*Startup: NAME*=.

#+begin_src emacs-lisp
(lispm-desktop-open-at-login t)
(setq lispm-desktop-startup-items
      '((:program "ollama serve")
        (:app browser)
        (:file "~/notes/todo.org")
        (:program "npm run dev" :name "Site" :directory "~/site/")))
#+end_src

** Updating

The Software Update panel keeps the checkouts in =~/.lispm= on their branches, checking daily or
weekly.  Updates install as LispM quits, never while it runs (Restart to Update installs at
once); a checkout with changes of its own is left alone.  The App Store updates its applications,
by itself once LispM is idle if you allow it.  =M-x lispm-desktop-update-now= checks from anywhere.

* Mac OS and X

One configuration runs in the Mac build (NS) and in an X build, detecting the display and
Emacs's features at each start.  X frames go without Emacs's own menu bar, which the λ menu
replaces.  Windows out on the screen, the pointer watch and Chrome extensions are Mac only; the
browser needs xwidgets (WebKitGTK on X).

On an X display with no window manager, Emacs becomes it with [[https://github.com/emacs-exwm/exwm][EXWM]], installed when first
needed; ~(setq lispm-desktop-window-manager nil)~ turns this off.  On GNU/Linux, end =~/.xinitrc=
with =exec emacs=.

** X on macOS

Build a second Emacs against Homebrew's X libraries (=libx11=, =cairo=, =harfbuzz=, =librsvg=),
not XQuartz's: two libX11s in one process do not mix.

#+begin_src sh
./configure --prefix=$HOME/.local/emacs-x11 --without-ns --with-x \
  --x-includes=/opt/homebrew/include --x-libraries=/opt/homebrew/lib \
  --with-x-toolkit=no --with-cairo --with-harfbuzz --with-rsvg \
  --with-xpm=ifavailable --without-gsettings --without-native-compilation
make && make install
#+end_src

XQuartz's rootless mode has its own window manager.  To let Emacs manage windows, give it a
display of its own with Xephyr, which comes with [[https://www.xquartz.org][XQuartz]]:

#+begin_src sh
export DISPLAY=$(launchctl getenv DISPLAY)                # XQuartz's display, where a shell lacks it
/opt/X11/bin/Xephyr :2 -screen 1440x900 -resizeable       # in one terminal
DISPLAY=:2 ~/.local/emacs-x11/bin/emacs                   # in another
#+end_src

Clicking into Xephyr grabs the keyboard and mouse; Control-Shift releases them.  Both builds
share one configuration and its state files; the one that quits last keeps its own.

* Development

=make test= runs the ERT tests and =make compile= checks for byte-compiler warnings; both need
LispM Browser, beside this checkout or named by =LISPM_BROWSER= (its =lisp/=).  =make native=
builds the terminal module and =make native-test= runs its tests.  The =terminal module= workflow
publishes prebuilt modules as the releases =term-module-VERSION=.
